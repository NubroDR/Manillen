# Legacy-bestanden

`ManillenGUI.py` bevatte de vroegere Tkinter/ipywidgets-selectors. `Manillen.ipynb` bevatte de oorspronkelijke notebook-workflow voor spelers, indelingen en paringen.

Deze bestanden worden niet meer door de actieve Shiny-app gebruikt. Ze zijn alleen bewaard als referentie en projectgeschiedenis. De actuele workflow start met `app.py`; de publieke viewer staat in `mirror_app/`.
